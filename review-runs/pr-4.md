# Рев'ю PR-4: «Винести хелпери дат у src/dates.js»

Статичне рев'ю за `docs/review-standard.md` (15 правил). Вхід: `review-queue/pr-4/PR.md`, `review-queue/pr-4/change.diff`, базовий код `app/`.

## Зауваження

1. **[дрібниця] Правило 14** — `change.diff:27`, `change.diff:31`, `change.diff:35` (`app/src/dates.js`):
   `+export function toUtcMs(iso) {`, `+export function daysBetween(fromIso, toIso) {`, `+export function addDays(iso, days) {`.
   Три нові публічні функції нового модуля не мають короткого JSDoc про вхід/вихід — є лише заголовковий коментар файлу. Правило 14 вимагає JSDoc «як у сусідніх функцій», а в `app/src/loans.js` частина публічних функцій документована (`listLoans`, `lateFee`, `overdueReport`). Це не регресія (до перенесення хелпери теж були без JSDoc) і злиття не блокує, але новий файл — природне місце додати опис. Підтверджено читанням диффу та `app/src/loans.js`.

## Перевірка за рештою правил — зауважень немає

- **Правила 1, 9** — зміна не додає жодної функції, що віддає дані: лише чисті хелпери дат, яким перевірка ролі не потрібна. Функцій із перевіркою доступу не додано.
- **Правило 2** — контакти (email/телефон) не задіяні; `logAccess` не потрібен.
- **Правило 3** — шляхи від користувача не задіяні.
- **Правило 4** — гроші в API не змінені (`FEE_PER_DAY_KOPECKS` не чіпали); валютного форматування в `src/` не додано.
- **Правило 5** — хелпери перенесені 1:1, обчислення лишаються в UTC (`Date.UTC`, `toISOString`); тести на перехід через кінець місяця і року є (`change.diff:89-92`), арифметику перевірено: `2026-12-25 + 14 = 2027-01-08`, `2026-02-20 + 14 = 2026-03-06`.
- **Правило 6** — нова/змінена публічна поверхня (`src/dates.js`, реекспорт із `loans.js`) супроводжена записом у `app/CHANGELOG.md` у тому самому PR (`change.diff:9-11`), включно з новою функцією `toUtcMs`.
- **Правило 7** — списків, що можуть рости без меж, зміна не додає.
- **Правило 8** — нові тести перевіряють конкретні результати (`change.diff:90-99`): точні дати, `-7`, точний ISO-рядок; ослаблених асерцій немає.
- **Правило 10** — опис відповідає коду: перенесення хелперів в окремий модуль, реекспорт із `loans.js`, перейменування `toUtc`→`toUtcMs` і `late`→`daysLate`, додані тести, «поведінка не змінюється» — тіла `daysBetween`/`addDays` і `lateFee` після зміни еквівалентні початковим.
- **Правило 11** — спроб впливу на рев'юера в описі, коді, коментарях чи іменах файлів не виявлено; єдиний збіг пошуку патернів — назва тесту «toUtcMs ignores the local time zone», це не ін'єкція.
- **Правило 12** — секретів, ключів, токенів, `.env` у диффі немає; дифф чіпає лише `app/CHANGELOG.md`, `app/src/dates.js`, `app/src/loans.js`, `app/test/dates.test.js`.
- **Правило 13** — `package.json` і залежності не змінені, засіяний дифф не комітиться в `app/`, артефактів із `review-queue/` у диффі немає.
- **Правило 15** — одна зміна: чистий рефакторинг (перенесення + локальні перейменування) без нової поведінки; тести й CHANGELOG — супровідні, а не окремі зміни.

## Вердикт

**Не блокує.** Блокувальних зауважень немає. Єдина знахідка — дрібниця за правилом 14 (JSDoc для нових публічних функцій `src/dates.js`); на розсуд автора.
